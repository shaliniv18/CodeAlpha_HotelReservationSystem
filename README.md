# Hotel Reservation System

## Task 4 — CodeAlpha Java Programming Internship

This project is a console-based **Hotel Reservation System** developed in Java as part of **Task 4** of the CodeAlpha Java Programming Internship.

The system allows users to search for available hotel rooms, book rooms, view booking details, cancel reservations, simulate payments, and store booking information using file handling.

---

## Features

- Search available hotel rooms
- Book a hotel room
- Room categorization:
  - Standard
  - Deluxe
  - Suite
- Enter customer name and phone number
- Simulate payment during booking
- Generate a unique Booking ID
- View booking details
- Cancel reservations
- View all bookings
- Automatically make cancelled rooms available again
- Save booking information in a text file
- Load previously saved bookings when the program starts
- Maintain room availability using saved booking data
- Use Object-Oriented Programming concepts
- Use Java ArrayList for managing rooms and reservations
- Use File I/O for persistent booking storage
